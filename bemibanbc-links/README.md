# bemibanbc-links

Link page for BEM Bahasa Iban Boulevard Centre. It's a static site with no build step.

## Structure

```
index.html            Page markup; edit the links here
assets/
  css/styles.css      Styles (brand colours are in :root)
  js/main.js          Footer year
  images/logo.png     Logo, also used as the favicon
```

## Deploy

Upload the whole folder as-is, with `index.html` at the site root.
